# tests/golden/tactic_decision_trace.golden.txt
#
# GATE G1 golden for the TacticDecisionPipeline decision trace
# (engine/game/tactic_pipeline, ADR-005 D1).
#
# [ORIGINAL] provenance: the decision order and line formats are the ARM
# binary's AI debug tracer strings at 0x8F798090..0x8F79834C
# (reverse/analysis/PORT_GAPS.md:171-178, MEMORY_INDEXING_R56.md §3.1,
# GOLDEN_TESTS.md §2 "AI decisions (GAP-4)"):
#
#   UseDefense -> UseSafeAttack -> TableAttack -> DodgeMissiles ->
#   QuickAttack[i] -> Evade[i] -> UseCautiousMovements
#   then DistanceError / FrameError / Intervals / EnemyIntervals /
#   DecisionType / Decision {Wait=%d}
#
# Methodology: each section is one decide() run over the synthetic tactic set
# in tests/test_tactic_decision_trace.cpp (kTacticXml) with a scripted
# TacticContext/TacticMemory and the seeded LCG (make_lcg). Expected values
# are computed from the documented score/curve formulas (tactic_settings.cpp
# Gb/QYa) and the LCG draws, not copied from engine output. A failing byte
# comparison = a real gap: stage reorder/merge/skip, value drift, or a
# memory/context wiring break.
#
# Re-pinning rule (R3/R4/R6 promotions): scenarios use extreme chance gates
# (always/never) and extreme fight states, so a comparator or wait-mapping
# change alters VALUES ONLY — never which stages fire or how many lines a
# stage prints. Re-baseline values, not line structure.
#
# `*` in a golden line matches "any digits" (format-only pin).
#   R4-promoted: the Wait value is formula-pinned (gate + duration arithmetic,
#   VERIFY_R34.md) but this scenario's inputs are not scripted, so section
#   `expected_wait` pins the line format only.
