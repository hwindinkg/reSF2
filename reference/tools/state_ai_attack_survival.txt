# SHARED input script: SURVIVAL fight with the PLAYER ATTACKING.
#
# Purpose: give the AI a real oracle reference for the case the user reports -
# "I hit the enemy and she never fights back". Every other scenario idles the
# player, so the Tabular AI's reaction path (de.ia gate + Gc reaction pump) is
# never exercised on the oracle side.
#
# One file drives BOTH sides:
#   oracle:  shell\bin\Release\net9.0-windows\OracleShell.exe ^
#              --query "postTutorial=1&skipFightNone=1&maxFrames=6000&battle=Survival" ^
#              --input-script reference/tools/state_ai_attack.txt --timeout-ms 90000
#   native:  game.exe --replay reference/tools/state_ai_attack.txt ^
#              --battle Survival --zone ZONE_1 --fight-ordinal 0 --location bamboo_grove ^
#              --headless 900 --dump-state 700 --watchdog 900 ...
#
# Navigation = the state_tournament.txt taps (the oracle reaches the fight that
# way; the native side boots it directly and ignores them). The `atframe` edges
# are FIGHT-frame anchored and land identically on both sides.
#
# Key codes (JS `Gz`/`Af.oUa` defaults): 68 = D (Forward), 76 = L (Kick),
# 75 = K (Punch).
