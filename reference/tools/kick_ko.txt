# Stage-2 KICK-ONLY fight input script (one file, BOTH sides).
#
# The port's `--kick-ko` probe drives the player with KICK taps only (control 10,
# GLFW 76 / browser keyCode 76 = "L") until the boss is knocked out, which is what
# makes every landed hit carry the `RestrictedAnimation` kick animation and fires
# the `KickFights` achievement counter. That probe teleports the fighters into
# range as a harness convenience, so it has NO oracle counterpart; this script is
# the shared, input-only version: navigate to the BOSS_LYNX fight (the taps are the
# same ones `state_boss_lynx.txt` uses, and the port's `--replay` ignores them
# because it boots the fight directly), then press Forward to close the distance and
# KICK repeatedly, at fight-frame anchors both sides share.
#
# ORACLE side:
#   shell\bin\Release\net9.0-windows\OracleShell.exe ^
#     --query "postTutorial=1&skipFightNone=1&maxFrames=9000&battle=BOSS_LYNX&battleZone=ZONE_1" ^
#     --input-script reference/tools/kick_ko.txt --timeout-ms 180000
# NATIVE side:
#   build\app\game\Release\game.exe --replay reference/tools/kick_ko.txt ^
#     --battle BOSS_LYNX --zone ZONE_1 --fight-ordinal 0 --location dojo ^
#     --headless 9000 --dump-state 9000 --watchdog 900 ^
#     reference/www/res reference/saves/save.xml
#
# Menu navigation (oracle only; the native `--replay` path boots straight in).
wait 8000
tap 180 98
wait 1500
